## 一键启动

Windows推荐使用Python 3.12，仓库根目录执行：

```powershell
.\start-demo.ps1
```

脚本在仓库本地创建`.venv`并安装演示依赖，然后启动`http://127.0.0.1:8080`。当前机器已有所需依赖，可直接运行：

```powershell
python scripts/run_demo.py --native-https
```

Windows上Python TLS连接异常时可用`-NativeHttps`或`--native-https`选择既有原生HTTPS连接；保留证书校验，凭据经stdin传递。该连接仅支持非流式文本请求，浏览器句子流来自会话承接和最终正文，并非放行主模型未校验的逐token回答。

默认只绑定本机。会议室其他设备需要明确设置`--host 0.0.0.0`并自行提供可信网络或反向代理的访问控制；远程麦克风需要HTTPS。服务为单进程演示工具，内存会话有64个上限，不提供生产多节点持久化或账号系统。

## 模式与现场操作

- 录制回放：默认模式，读取exp44保存的7轮原始对话，不调用模型、ASR或云TTS；可以使用浏览器朗读。只能顺序播放录制问题，原T06失败和T07人工请求保留，不冒充当前版本成功答复。
- 实时DeepSeek：沿用冻结核心的主模型；需要Qwen与DeepSeek凭据。当前本机没有DeepSeek凭据，入口明确禁用，没有静默替换模型。
- 实时Qwen对照：具备Qwen配置时可用。Qwen主回答额外收到v4任务ID/结构提示，避免沿用旧单轮示例而漏后台待办；不改写或修补模型答案，所有核心来源、条件与发布检查保留。该模式不代表冻结DeepSeek或exp44成绩。

演示顺序建议：先回放查看原始链路，再切到配置好的实时模式，选择报价更正、复合保障、缺条件测算或病史边界场景。每次问题结束后可继续补充或更正，右侧查看条件、未完成问项与依据。

可以停止回答、导出JSON会话、新建会话。文字模式必须显式点击“已读完”后提交已读历史；朗读模式按已播完句子发送回执。取消时不提交未播答句，旧回执和旧WebSocket消息不恢复新会话。生成过程中使用隔离的会话副本，取消后丢弃迟到模型状态。

## 语音与动作说明

浏览器录音启用echoCancellation、noiseSuppression，发送16kHz单声道PCM到Python服务，再由服务签名接入腾讯ASR。签名与服务密钥不发送给浏览器。按录音按钮会显式停止当前回答；本页没有宣称连续开放麦克风或自然打断已达标。

实时模式可选Qwen云TTS，每句合成WAV后传给浏览器；云TTS失败时明确提供浏览器朗读或文字确认。浏览器句尾播放回执用于工程状态管理，不等于扬声器实际声学输出、DAC验收或客户电话侧回执。

短信与真实人工接通未集成。Web适配把旧成功话术替换成“已记录请求，尚未接入/接通”，保留门禁和人工请求数据，不报告虚假动作成功。回放中的原话仅代表历史记录。

## 配置与容器

复制`.env.demo.example`为Git忽略的`.env.demo`，填入对应服务配置。现有`.env`和`.env.deepseek`继续可用；不用把密钥粘贴到网页。没配密钥也可以运行全部回放。

```powershell
docker compose up --build -d
```

Docker镜像只打包核心、业务数据（含原始PDF/工作簿与提取文件）、网页、冻结清单和回放所需7轮JSON，不复制密钥、录音、缓存或整个实验结果目录。Compose默认将端口发布到本机127.0.0.1，凭据由可选`.env.demo`提供。当前环境没有Docker，因此容器文件已提供，但没有实际构建或运行容器。

## 本次验证与局限

136项全套单元测试通过，其中12项Web适配测试覆盖会话隔离、同源限制、输入校验、无云调用回放、已播句提交、乱序/迟到回执拒收、在途取消后不提交旧画像，未集成动作不报成功，以及跨系统路径/换行来源验证。冻结核心SHA-256核对通过。

本机浏览器验证：桌面1440×1000、窄屏390×844无横向溢出；7轮回放完成且保留原始失败，无页面脚本异常。实时Qwen通过两轮报价：35岁有医保年缴423元，更正无医保后971元。Windows原生HTTPS下两轮文字就绪约23.18秒、26.02秒，不能解释为正式首响或完整口播时延。

云TTS实测“我三十五岁，有医保。”首包约0.213秒，生成1.84秒音频；合成音频通过Web ASR转发接口识别为“我35岁，有医保。”。浏览器模拟麦克风到Web ASR的完整路径也已走通，但循环合成输入出现重复/误识别，不计入准确率。界面文字、次要文字、主按钮对比度分别约15.17、5.84、5.19，均≥4.5。以上是服务连通性测试，没有真人麦克风、物理AEC或电话侧验收。当前本机DeepSeek没有凭据，未重验DeepSeek完整业务；此前缺结构或缺task_ids的Qwen尝试被核心待办检查拦下，未发布其业务正文。

本地截图、浏览器记录、音频连通结果与运行日志放在Git忽略的`demo-runtime/`。冻结业务指标仍以[24-当前指标与验收口径](24-当前指标与验收口径.md)为准：复杂/复合子集86.7%，完整口播≤10秒、自然打断、来源支持和安全路由仍有缺口。
