# DS Flash 精简提示词对照（2026-10-11）

用户要求：先试 prompt 选择本轮必答事实再生成短答。DeepSeek 服务已恢复；全部生成使用 `deepseek-flash`、关闭 thinking、temperature=0.3。未调用 STT/TTS，未切换生产提示词。

## 第一组：保留当前槽位链路

8题×2提示词×2轮，共32次完整回答调用。每题理解与检索只准备一次，两种提示词共享输入，第二轮反转版本顺序。比较当前提示词与“内部选必答事实、共用条件只说一次、未问细节留白”的新系统提示词。

|指标|当前|新提示词|
|---|---:|---:|
|每版有效调用|16|16|
|最终字数中位数|65|107|
|回答阶段耗时中位数（秒）|1.540|1.333|

此组未改善简洁性。当前理解会把“区别”扩成5个槽位，包括未明确问到的医院范围；用户消息又要求每个槽位必须回答，抵消了系统提示词的留白要求。两版还受到错误缺口判定、数字护栏误判“一天”及全局兜底影响，不能用最终短兜底的字数评价生成质量。

代码：`experiments/exp24_ds_minimum_prompt.py`。原始结果及完整系统提示词：`experiments/results/exp24_ds_minimum_prompt.json`。

## 第二组：纯文本 prompt 对照

仍为相同8题、2轮、2版本，共32次。直接复用第一组记录的逐题证据，不调用新的理解或检索。两版输入都只包含同一份资料、原用户问题和纯文本输出要求；只改变系统提示词，不做程序选事实、截断或模板替换。护栏结果另行记录，不改写原始输出。

|指标|当前|新提示词|
|---|---:|---:|
|每版有效调用|16|16|
|原始字数中位数|106|81.5|
|生成耗时中位数（秒）|0.981|0.863|

中位字数减少23.1%，生成耗时减少约11.9%。这是生成阶段，不是完整链路耗时，也不是首声或播放时长。小样本包含既有复杂题与2道简单题，不能推广为全量结果。

示例：问“药省保每月最多报多少”，新提示词第一轮直接回答“药省保每月赔付限额100元。”；无需主动介绍年度上限、比例和等待期。

## 人工检查与结论

Prompt 能影响取舍，单纯更换系统提示词却不足以克服旧槽位要求。取消强制扩写要求后，简洁性有所改善，但仍未满足全部质量要求：

- C19用户问基因检测与特药申请和额度，新版两轮均未说特药600万额度，且一轮把社保目录内药品“未用社保结算按60%”省成缺少投保社保身份前提的说法。
- C27新版一轮仍主动列2人、3人优惠；另一轮省略一般门急诊不参与家庭共享的范围说明。
- C07新版仍带有较多金额和细节，未稳定压到70字以内；70字仅为软目标，不能靠截断实现。
- 原数字护栏对“500元一天”的“一天”会误报，原链路错误核保路由还会吞掉一般保障问题。这些不由精简系统提示词解决。

因此本次结论是“prompt-only可改善表达，但当前候选未通过复杂题完整性检查”。保留候选用于后续修订，不直接覆盖生产提示词。下一版需同时精简理解/输出要求，明确金额题每项额度均必答、比例的身份前提不可省，再做成对验证。

代码：`experiments/exp24_ds_plain_prompt.py`。完整输出、耗时、证据ID及护栏记录：`experiments/results/exp24_ds_plain_prompt.json`。不使用自动事实复核的“通过”代替人工正确性结论。
