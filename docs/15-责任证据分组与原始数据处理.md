# 责任证据分组与原始数据处理

2026-10-11。本轮继续验证证据组织能否改善准确性，模型仍为 `deepseek-flash`，不调STT/TTS，不切换生产默认，不做回答反思或规则修复。

## 结果

主 agent 阅读两版全部142条最终回答并逐题对照来源，再阅读新增16题两版共32条回答。评分是主 agent 的源审查判断，**本轮没有完成另一个独立审查者的双审**，不应描述成人类标注或独立认证准确率。

71题仅多通过一题，不足以证明稳定超过90%。新16题是在分析开发集错误后设计的新问法和边界题，问题在调用前保存冻结，但**不是独立抽样的外部盲测集**。两版都通过14题，未证明新组织方式已经普遍提高内容正确率。

本轮更可靠的观察是责任上下文与引用绑定有所改善。引用单位也从单元格变成含完整父责任的证据包，因此溯源提升部分来自引用呈现更完整，不能全归因于模型理解能力提高。引用有原文仍不保证答案正确。

中位完整文字生成耗时：证据分组版2.27秒，更强提示版2.14秒。新增16题分组版2.33秒、旧版2.11秒。均是云端全部文字/JSON完成时间，不能当成首音；并发条件不构成隔离性能基准。

## 当前原始数据怎样处理

### 1. 原件保留

`data/raw/尊享百万/`有责任Excel、投保须知PDF、免责PDF、年缴/月缴费率PDF及场景说明。不是每轮在线读取这些原件。

### 2. PDF文字提取与保真清洗

`scripts/extract_data.py`分别用pdfplumber、pypdf提取各页，原提取结果保存至`data/extracted/pdf_text/`。主要使用pdfplumber文字，去硬换行、布局空格，按序号插入换行；没有用模型摘要改写条款。

清洗结果在`data/clean/text/*.md`，保留页码标记、原PDF路径和SHA256。脚本断言去掉空白后清洗文字与原提取文字相同；已有`data/extraction_report.json`记录两种提取器各页一致。

**这只能证明转录/清洗一致，不能证明条款之间的关系已整理正确，也不能自动发现原件本身的冲突。**页内按行分片也可能把标题、条件与后面的金额拆开。

### 3. Excel结构化

同一脚本读取原单元格及格式，记录合并区域，将合并字段向下填入所属责任；百分比按显示格式转为百分号。按责任名称形成R01–R16，保存基础/加油包归属、人群、等待期、额度、比例、免赔、医院及全部D列描述。保留源行号、D列坐标、原文件哈希；提取脚本有非空单元格内容都被保留的断言。

本轮重新检查了清洗责任JSON记录的SHA256，仍与当前原始Excel一致。没有重写保险事实。

### 4. 费率图片转录为CSV

费率PDF的表格以图片为来源，当前四张CSV是转录出的年龄区间和各计划费率。`scripts/verify_premium_ocr.py`使用独立OCR按年龄行/列核对，处理水印和背景造成的识别问题；脚本保存部分历史视觉确认记录。横杠等未被OCR确认的项仍需视觉核对，不能说所有内容都仅靠OCR自动验证。

运行时字段化只是将同一CSV行呈现为“年龄=[26,30]；必选计划_有社保=318.0……”；没有凭模型生成新价格。表中71+费率不能推导保证续保到费率最高年龄。

### 5. 切片和检索

`src/agent/knowledge.py`将责任D列描述及须知/免责行做成带ID、源页码或单元格位置的Chunk。默认链路使用词法TF-IDF排序与向量相似度排序，通过RRF合并。

**上轮88.7%的实验版与本轮分组版直接提供完整证据包，不是只给检索出的前几段。**处理后的数据与完整证据是否提供，是两个不同问题。

## 本轮改变了什么

旧版责任证据虽然同一责任的原文都在包里，但以`R01:head`、`R01:D8`等分开出现。模型引用金额单元格时容易缺少父责任归属、适用条件和医院限制。

新版`grouped_evidence()`把每项责任的原始字段和所有原始描述组成一个bundle；仍保留原单元格ID与位置，不推断新的规则。不把医疗报销、津贴或附加服务压成一个共同比例。

模型可能引用bundle或包内声明的单元格ID。`source_registry()`将包内ID解析到完整所属责任上下文，保证追溯时不丢失父字段。最终引用是原始内容的结构化呈现，不伪装成PDF原排版逐字摘录。原始位置仍可回到Excel和清洗文件。

另一个版本使用相同包，再加责任边界、已有病史和来源冲突提示。这个版本没有更好，反而新增“意外也等30天”等错误，不能靠一直加提示词假定准确率会上升。

## 修好的题和回退的题

相对上一版，单改证据组织：

- C01：避免把医院/身份各种不满足情形用一个“否则60%”合并。
- C02：质子重离子明确中国大陆范围。
- C29：补上符合合同重疾定义时无免赔的分支。
- C05：回退为只讲一般住院扣1万，没有给中风符合合同重疾时的住院分支。
- Y036：牙科矫正变成一概不赔，漏掉原文意外例外。

所以是修好3题、新增失败2题，净改善1题。原71题分组版仍失败：C05、C07、C09、C19、C20、Y015、Y036。

新增16题中两版均失败N07、N08：

- N07明确“买之前已查出结节”，仍绕回“是否认定既往症”；分组版还继续追加未医保60%，没有直接处理这笔已知既往相关费用。
- N08明确“营运货车、总质量4吨”，职业表包含4吨及以上，两版仍保留过多核保不确定话术，分组版甚至建议尝试投保。这里已有具体职业限制，不应把明确证据降成不确定。

这些判断按严格的“回答当前已知情境”口径审查。条件化留白与未完整回答之间存在主观边界；全部判定理由保存，不将90.1%视为经过统计认证的事实正确概率。

正确的边界例包括：30/31岁分别差54/81元；无医保身份不强套60%；医保身份未结算15000元按假设赔3000；孕妇骨折与分娩按原因区分；门诊不进家庭共享免赔；6岁含以下不能开处方；车祸津贴不等疾病30天；费率105岁不等于保证续保。

## 是否应从原始数据处理入手

应该，重点是从保真转录进一步做**有来源的结构化证据**，不只是继续清洗文字或扩充提示词：

1. 保留每项责任的父级归属和完整条件句，尤其“意外或等待期后疾病”“有医保身份且未医保结算”，不要用一个等待期/比例字段代替条件逻辑。
2. 费率字段需要显式区分年龄、首投/重新投保适用、社保、性别、计费频率和计划；医保列不能读成性别列，年龄费率不能当承保保证。
3. PDF切片需要保留标题、段落、页码与从属关系；目前孤立行不适合证明“仅此加油包”“资料没有某项”。
4. 主体保险给付与附加服务备注需要分层；基因检测D49一万与D52服务不限额的适用范围，应先对照完整合同确认，不能由模型自行裁决成单一事实。
5. 补充原件目前引用但未提供的完整合同定义/药品清单等资料，缺失证据不能靠提示词补成事实。明确来源权威与版本，冲突保留双方出处。

这些是后续方向。本轮已经实现责任bundle和上下文引用；没有宣称已实现完整条件逻辑结构、PDF标题树或已解决原件冲突。
