# 答辩演示版实现与验证

2026-10-14，参赛者陈为，个人参赛。新版标签`v0.2.0-defense-20261014`，继续使用冻结核心`v0.1.0-core-20261014`；不覆盖旧标签或历史失败记录。

## 现场自由问题

配置DeepSeek后首页默认进入实时咨询，使用腾讯ASR识别现场新问题、冻结业务链路生成并检查答复、云TTS朗读。DeepSeek未配置时回放入口可用，并明确提示缺配置，不静默改为Qwen。Qwen作为主动选择的对照模式保留，不代表DeepSeek官方指标。

“说完自动发送”默认开启，在ASR返回完成句段后结束录音并提交问题；可关闭以编辑识别文本后再发送。点击录音会显式停止旧回答，停止后不接纳迟到播放回执。每轮需主动点击开始录音，未实现持续开放麦克风的自然全双工会话。

播放速度有0.75、1、1.25、1.5、2倍。云音频可即时改变当前播放速度；浏览器语音按下一句的速度设置。速度不改变生成正文，也不提高原速验收指标。

## 耗时口径

| 数据 | 计时方式 |
|---|---|
| ASR连接 | 浏览器创建录音连接到收到识别服务ready |
| 语音采集 | ASR ready到本轮结束录音，包括等待语音终点的间隔 |
| 识别确认 | 浏览器结束录音到ASR done；与采集时长分开 |
| 理解、证据准备、生成与校验 | 服务器perf_counter阶段范围；部分步骤并行，不可相加 |
| 模型API | 每次实际调用的开始/结束、模型名、token用量；重试分别记录，不存密钥或提示词 |
| 文本就绪 | 当前用户文本进入会话处理后，核心本轮生成和检查结束；不等到音频全部合成 |
| TTS连接与逐句合成 | 服务器连接、首包、合成时间和原速音频长度 |
| 首声、正文首声 | 浏览器Audio playing或SpeechSynthesis start，起点为发送已识别的文本；固定承接独立记录 |
| 完整播完 | 所有句子结束后记录；停止或播放失败不报告为完整播完 |

网页首声起点是文本提交，**不是用户声学句尾**；还需查看ASR采集与终点延迟。浏览器事件不是物理扬声器或DAC出声。回放仅显示回放操作耗时，历史真实DAC整轮数据在处理记录里标注。固定承接不代表业务正文，生成完成不代表用户听完。

每轮都创建独立观测客户端和会话候选，不使用跨会话共享的计时变量。云调用和理解线程将事件推到异步队列，由WebSocket实时展示；取消后不发布旧线程的答案或画像。

## 溯源与完整记录

引用区同时保留答句、引用ID、引用原文和原始定位。点击“核对完整原始证据”从服务器允许的证据索引获取全文、来源描述、材料路径与SHA-256，不允许浏览器请求任意磁盘文件。按责任分组的证据会返回完整所属责任上下文，防止只拿孤立字段。

“完整对话记录”按轮展示用户问题、完整生成内容、已播完句子和取消标记，可回看任一轮的耗时与来源。导出JSON包含完整记录、阶段测量、浏览器计时、来源与会话状态。已生成记录与送入下一轮的已播历史分别保留；未播正文不成为用户已听到的答案。会话保存在单进程内存，关闭前应导出，刷新页面不会自动恢复旧会话。

## 验证

142项程序测试通过，冻结核心哈希校验通过。新增测试检查失败API仍有结束计时且不记录敏感参数、客户端选项保持观测器、迟到/无效浏览器指标不能污染历史、取消后的生成与已播记录不重复，以及来源端点只返回允许的证据。

桌面1440×1000、移动390×844验证无横向溢出；回放、原始证据端点、历史记录、15分钟演练计时器可操作。真实云服务的Qwen对照报价测试：35岁、有医保、首次必选个人单年缴423元；2倍速，浏览器承接首声约1.78秒、业务正文首声25.76秒、整轮播完29.93秒，服务器生成与校验24.02秒。此为适配连通性样本，既非DeepSeek成绩，也非正式声学时延验收。

合成麦克风端到端输入“住院的等待期是多少天？”被正确识别并自动提交，Qwen对照回答等待期30天且完成句尾回执。识别连接0.39秒，录音采集（含终点等待）5.08秒，结束到识别确认0.12秒；文本提交后的承接首声0.83秒，业务正文首声22.49秒，1.5倍速整轮播完33.95秒，生成与校验18.89秒。页面脚本错误0，桌面与移动无横向溢出。这是合成输入连通验证，不证明真人ASR准确率、声学时延或AEC。

配置状态与测试结果在资料包`materials/`内保存，包含可离线打开的`现场结果演示.html`和完整实测JSON。当前机器DeepSeek密钥缺失，尚未验证该版本现场DeepSeek全链路。配置模板见`.env.demo.example`，补好后重启并预演新问题；Docker运行仍未实测。
