# 简洁界面与持续语音交互

2026-10-14。版本`v0.3.0-duplex-20261014`，保留冻结核心`v0.1.0-core-20261014`及前两版标签。

## 页面与操作

默认单列对话，保留“开启语音 / 结束语音”“停止回答”、语速和文字发送。场景、模型与云语音配置移到“设置”；耗时、来源、画像、待办、完整对话、导出和验证范围移到“核对记录”。每条完成答复也有“查看本轮”入口。侧栏默认关闭，支持关闭按钮、Escape以及移动端背景点击，隐藏内容不占据主对话屏幕。

配置DeepSeek后默认实时模式。未配置时保留回放，点击开启语音会引导到设置，不静默换模型。可主动选择已配置的Qwen对照用于连通性测试；不是DeepSeek成绩。模式切换与新会话会释放原麦克风。

## 持续收音与插话

点击一次“开启语音”后，浏览器MediaStream与AudioWorklet保持运行，发送16kHz PCM，模型生成和回答播放都不关闭麦克风。腾讯ASR的`slice_type=2`是当前句段完成，不是整条连接结束；客户端按`index`去重，每个新完成句段可以触发下一轮。该字段含义见[腾讯实时语音识别协议](https://cloud.tencent.com/document/product/1093/48982)。

AudioWorklet每40毫秒提供PCM和RMS音量；持续高于自适应底噪阈值约120毫秒后触发人声候选。正在回答时先暂停播报和后续句子队列，不立即提交全部停止状态。ASR中间文本若为实质问题、更正或叫停，确认插话并请求服务器取消旧生成；等待停止回执后再提交新问题。附和和与正在播放答句相同的较长文本分别按附和、疑似回声处理，恢复旧播报。噪声无识别结果时在静音后恢复。

“嗯，好的”等纯附和在回答过程中不成为新咨询；“好的，那月缴多少”会进入新问题。“停止回答”等单纯叫停停止旧回答，不另发一次业务生成。空闲时的“好的”仍允许进入原会话流程，避免吞掉用户确认。长句停顿会被ASR分段，关闭“说完自动提交”后可编辑识别文本再发送。

每条ASR连接约48秒后在无未完成语句时续期，MediaStream保持不变，短暂连接间隙缓存最多1.6秒PCM。意外断开有限重试，连续失败会释放麦克风并明确提示。结束语音、新会话、关闭页面或会话结束都会停止音轨和采集。播放与已播历史仍按完整句尾回执处理，未播完句子不写入下一轮已播历史。

## 实测

143项Python测试和7项Node语音状态测试通过；核心冻结哈希通过。Node检查持续人声与单次噪声、附和/回声/叫停/新问题区别、同一连接多句去重、ASR部分文本仅取消一次，以及单纯叫停不发新业务问题。新增服务器检查观察事件不改业务历史、拒绝非法事件并限制数量。

真实腾讯ASR、Qwen对照模型、云TTS与浏览器播放验证，输入通过合成音频注入MediaStream，未使用真人麦克风或物理回声：

1. 一次调用getUserMedia、一次点击开启语音，询问35岁有医保年缴保费，生成423元。
2. 等业务正文真正开始播放时，说“说错了，我没有医保，年缴重新算”。本地VAD候选暂停约0.160秒，ASR部分文本确认插话约0.894秒；起点是浏览器RMS人声候选的首帧，不是用户声学句尾。
3. 首轮记录保留完整生成文本，但已播文本只有“我帮您查一下。您关心的保费，我一起核对。”，未播完的423元不进入已播历史。
4. 第二轮更新为35岁、无医保，答出971元并完成播放；无需再次开启麦克风。
5. 过程中ASR连接续期一次，采集音轨仍为同一条；结束语音后音轨变为ended。

桌面1440×1000与移动390×844无横向溢出，侧栏打开/关闭和Escape可操作，页面脚本错误0。完整实测JSON、截图放在资料包`materials/`。第二轮原速承接首声3.77秒、业务正文首声24.06秒、整轮播完34.84秒，服务器生成与校验21.86秒；该样本不作为正式声学验收。

## 能力边界

本版实现浏览器层持续双向语音与插话取消，不据此宣布KR2已达标。局部噪声暂停、附和与文本回声抑制是当前启发式；外放、远端会议音频、用户重复AI原话、真人噪声下仍可能误判。浏览器AEC请求不等于物理AEC验收，推荐耳机并实际预演。没有实测真人打断成功率≥95%，也没有自动改变exp44正式指标。

当前本机DeepSeek密钥仍缺失，实测主回答为明确标注的Qwen对照。接入DeepSeek后必须重启、提出新问题并实际插话预演。正式复杂准确率、来源支持、人工路由和完整口播仍以[当前指标](24-当前指标与验收口径.md)为准。

## 复现实测操作

网页服务运行且对应云配置齐全后，另一个终端安装可选测试依赖：`python -m pip install playwright`、`python -m playwright install chromium`，然后运行`python scripts/reproduce_duplex.py --provider deepseek`。Qwen对照用`--provider qwen`，已有浏览器可通过`--browser-path`指定路径。脚本实际调用付费ASR、模型和TTS，默认生成同样的两条合成问题，在第一轮正文播放时注入更正，检查只开启一次麦克风、取消旧回答、971元更正和音轨释放；结果写入Git忽略的`demo-runtime/`。脚本中的合成输入用于可控复核，不代表真人准确率或物理AEC。

基础启动和离线回放不需要Playwright或Node。先使用`python scripts/check_demo.py`检查配置，网络或模型响应异常会导致复现实验未通过，保留结果复核，不删除失败分母。
