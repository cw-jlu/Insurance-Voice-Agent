## 3. 13个回答错误逐项说明

下表的原因是从可观察输出推断的机制，不代表读取了模型内部思考过程。相关证据已在本轮完整输入里，没有发现这些错误由召回漏掉条款造成。

| 题号 | 回答的问题 | 原文支持的边界/正确处理 | 发生位置与原因 |
|---|---|---|---|
| C05 | 中风住院只给一般医疗扣1万，未答重疾住院无免赔分支 | R03:D19、D24：满足合同100种重疾的住院路径无免赔；不能只泛称可能重疾而省略其给付区别 | 生成时遗漏复合问题必要分支 |
| C09 | 已有高血压仍转到“如果不是既往症” | 责任免除#3/#4/#9：直接说明当前既往相关费用边界，核保与费用免责区分 | 条款复述正确，但没有落实用户已知病史 |
| C12 | 先讲结节20%，又说医保未结时补偿包都会改60% | R12:D107/D108同时出现，当前责任包未明确组合优先级；应保留组合未知 | 把两条正确单独事实组合成无依据的覆盖规则 |
| C19 | 只答增值服务100%不限额、医院路径60%一万 | 原xlsx D49：主体检测费用限1万；D52：增值服务100%不限额；需说明主体/服务范围差异待确认 | 原资料冲突已提供，但模型隐去了一侧 |
| C20 | 用户投前已有结节，追加补偿包时仍给结节20% | 已有同一结节相关手术受既往症免责，不能暗示加包解除免责 | 已知事实未贯穿到新增责任段 |
| N07 | 先说结节补偿“确实20%”，末尾才说既往相关不赔、待认定 | 用户已明确投前查出结节；不能先承诺该病20%，也不能无依据用60%覆盖20% | 免责条件优先级与用户事实应用失败 |
| N08 | 先因42岁说“可以投保”，后说4吨营运货车可能不能 | 须知#88及#110：该职业在排除表；年龄符合不足以推出整体符合 | 局部年龄资格被写成整体资格，首尾矛盾 |
| N09 | 用户56岁按指定期限重新投保，却因首次55岁上限拒绝；随后又引1019费率 | 年缴费率说明页1提取行1—5：56岁及以上门诊包属于指定期限重新投保费率适用情形；仍需其他承保条件，不等于保证续保 | 首次和指定期限重新投保分支选错 |
| E05 | 女性31岁报价56元正确，却额外说重疾关爱必须等待30天初诊“才”给付 | 原xlsx D99另有意外导致罹患路径 | 不必要的扩写把条件缩窄，额外事实使整答失败 |
| E08 | 2万元合规费用、医保已报1万、免赔未用，回答赔1万 | 免责#2已明确医保已报部分不赔；按题设应max(20000−10000医保−10000免赔,0)=0 | 所引证据里有补偿原则，计算公式却漏应用 |
| E09 | 年免赔已抵6000，仍重扣完整1万，回答0 | 剩余免赔10000−6000=4000；若9000是个人剩余合规费用，则赔5000 | 年度累计状态未参与计算 |
| E19 | 承认已抵7000可共享，却把剩余免赔算成1000，回答4000 | 剩余免赔10000−7000=3000；若5000是个人剩余合规费用，则赔2000 | 明确算术错误，不能靠正确引用补救 |
| E31 | 基础摘要没写床位1500，回答基础“没有”该限制 | R01摘要未见，R05/R11有1500；完整基础合同费用定义缺失，不能把未记载升级成无约束 | 资料缺口被写成确定性否定 |

E09/E19题干虽说已医保结算，但未量化该次医保报销金额。上表的5000/2000按合规费用为医保后个人费用的常用测试口径计算；如果数字含医保已报部分，应补问金额再扣。即使采用后一口径，本轮把年度免赔重新归零、或10000−7000算成1000仍然明确错误。此次记录保留题干和歧义说明，没有修改问题后回填结果。

### 一条可定位的错误trace：E08

1. 用户：总费用20000，医保已报10000，年度免赔未用。
2. 输入已经包含R01:D8/D10及责任免除#2。模型实际也引用了责任免除#2。
3. 模型输出公式：`(20000-10000)×100%=10000`，只减去一笔10000；没有同时扣除医保已报和年度免赔。还反问是否医保结算，忽略用户已经给出的事实。
4. 责任免除#2原文：已经从医保等途径报销/补偿的部分不予理赔；R01:D8年免赔1万。两者组合后为0。
5. 因此错误位于模型应用条件并构造公式的阶段；定位/ID/原文字面校验会通过，却无法证明答案公式正确。

### 一条正确且知道留白的trace：E25

模型读到R12:D107（有医保身份未结算60%）与D108（结节20%），明确说当前资料没有写二者同时满足的组合方式，不选择20%、60%或12%。该判定可在完整R12责任包内核查。它证明模型有能力处理冲突，但C12/N07仍不稳定；也说明不能把C12期望答案硬写成某个唯一比例。

### 复核时排除的一项初步误判

Y012的“同病因、间隔不超过30日视为同一次ICU住院”不是把一般津贴条件错误迁移。直接读取原始xlsx的D118确认ICU条款本身也有此规定，本轮Y012通过。此例说明评审也必须定位原始单元格，不能只读摘要或依赖记忆。

## 4. 8个内容通过、严格溯源未通过的题

- C22：救护车各路径金额正确，但“康复相关救护只有此责任”属于排他断言；所引局部责任无法证明全集排他关系。不据此认定实际赔付结论已证实错误。
- Y026、Y034、Y040、N15：不承诺最高续保年龄/续保保证是合理留白，但“全资料没有某续保规定/价格”缺资料范围证据；N15该段引用为空。
- E32、E33、E34：不编造完整药品、重疾定义、医院清单是正确的，但仅引用责任名称和范围，不能充分证明当前所有附件都没有完整清单。E34额外“保险公司最新公布名单”也缺直接更新规则来源。

严格溯源并非要求未知问题必须给确定答案；要求明确“在当前哪些已提供文件/附件中未找到”，并有材料目录及缺失项记录支持。局部责任包内未定义组合（E25）与跨全资料集合的缺失断言采用不同范围标准。

## 5. 下一步优先方向

1. **证据先补好**：增加来源目录、已提供/缺失附件清单；责任/增值服务标注各自出处和适用范围；D49/D52及D107/D108保留冲突记录，缺原文时不人工编唯一结论。
2. **年度与补偿语义显式化**：证据卡说明免赔是年度累计、已抵扣与剩余额度区分；费用输入区分总费用、医保已报、个人剩余。模型输出需使用用户已知数值，而非重复默认“免赔未用”。错误公式不能仅凭引用合法被放行。
3. **资格条件分支讲清**：在证据中成对展示首次/指定期限重新投保、年龄/职业条件；提示词要求先适用用户已知事实，再写短结论，避免先可以后不可以。
4. **减少额外扩写**：只问价格时给价格和必要报价条件。E05报价本来正确，是多写给付条件引入错误。

本轮冻结跑分未修改提示词、生成答案或生产默认链路。上述为下一版应验证的方向；不能据此预先声称准确率提高，也没有加入在线反思或规则修复。
