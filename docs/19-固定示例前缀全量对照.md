## 设计与实现

exp31重新调用对照与v1，每题各一次，共270次。复核后冻结v2，再调用135次；v2比较的是保存的exp31对照和v1，属于顺序开发试验，非同时三组试验。三版问题、已知用户信息与证据包一致；运行计划记录提示词及材料哈希。没有根据答案修复或择优重采样。

v1保留8个虚构示例。v2增加4个虚构例：现在患病、未来购买的时间关系；意外或疾病等待期的并列分支；复合问题普通医疗与重大疾病的免赔差别；职业表已提供时核对具体条件。示例使用虚构疾病、金额和DEMO来源，不复制真实客户记录或实际产品答案。固定前缀提示模型仅使用本轮真实证据。仍是完整整理材料的一次生成，没有增加在线反思、辩论或规则修答。

源码：`src/agent/evidence_answer.py`、`src/agent/prompts/evidence_fewshot_v1.json`、`src/agent/prompts/evidence_fewshot_v2_additions.json`。生产默认链路未切换，v2通过实验参数选择。

判定以整段答案为单位：金额或是否赔的结论正确，但新增错误的必要限制，仍计错；引用ID真实不等于引用支持结论。全材料缺失某清单的否定，需要资料范围证据，不能仅靠一条责任描述证明。E09/E19沿用个人剩余费用解释，原题医保报销金额未明确的歧义保留。

历史exp29同127题为114/127（89.8%）、正确且可溯源106/127（83.5%）；它是另一批生成样本，不作为本轮配对对照。历史数与新对照86.6%的不同说明单次生成会波动。exp30难题富集29题的结果也不能当全量准确率。

## 改善、退步和残余错误

v2相对v1改善：C07、C13、C20、C25、C29、Y028、Y032、N07。

v2相对v1退步：C15、C21、Y002、Y022、Y033、E08、E22。

例如N07明确指出投保前甲状腺结节手术因既往症不赔，不再仅给补偿包20%；C29补齐合同重大疾病0免赔与一般医疗1万元免赔两分支。F01合规总费用32000、医保11000、年度免赔已抵扣6000，得到32000−11000−4000=17000，计算段引用一般责任与已补偿不赔原文。

v2剩余12道整答错误：

| ID | 原因 |
|---|---|
| C09 | 现在已有高血压、未来买仍当成未知投前关系；又把意外费用一概排除既往症免责，未限制为与病史无关 |
| C11 | 私立VIP问题只给公立特需路径，漏指定民营VIP |
| C15、Y002、E28 | 把疾病等待期扩成责任整体必须等待，漏意外分支；E28普通疾病不能领转诊的主要结论其实正确 |
| C19 | 基因检测只给主体限1万，漏服务备注不限额的冲突 |
| C21 | 加入院外特药路径后统一要求1万免赔和普通部就诊，未分开特药0免赔、指定药店路径 |
| Y022 | 把有医保身份且结算写成100%的必要条件，漏无医保默认100路径 |
| Y033、Y034 | 混淆71岁以上费率适用与及时重新投保资格；Y034直接把首次或未及时重投费率套给及时重投 |
| E08 | 数值0正确，但又称20000全为个人支付费用再扣医保，文字混淆总费与个人费用口径 |
| E22 | 无关车祸不能按结节免责的结论正确，但末句就诊条件缩为二级公立医院，漏指定民营 |

因此12道并非全是核心金额/是否赔错误，一部分是回答多写了错误条件。整答口径始终将这种额外错误计入。

另12道答案内容正确但引用不完整：C05、C07、C14、C18、Y015、Y039、Y040、N15、E32、E33、E34、E36。主要是资料缺失结论没有资料范围引用，或计算合计、核保结论未引用完整依据。逐题理由见审计JSON。
