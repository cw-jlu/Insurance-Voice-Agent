# 证据与独立辩论准确率实测

日期：2026-10-11。目标是提高事实准确性和可溯源性，实验回答不经过反思修复、固定答案拼装或规则改写。新增实现为 `src/agent/evidence_answer.py`，暂未切换生产默认链路。

## 结论

本轮最好的版本是完整原文证据、带字段名的费率、必要条件提示词和逐句来源绑定。主 agent 将其71题全部逐题对照原文：内容合格63题（88.7%），引用充分54题（76.1%），**内容与引用同时合格53题（74.6%）**。还没有达到可以宣称准确性有保证的程度。

独立辩论在这批题上没有优势，耗时明显增加。当前推荐继续优化证据的结构与来源归属，而不是默认加入多轮辩论或反思。

## 实验口径

- 固定71题：30道复合题及41道单轮题；六个版本共426次最终回答试验。早期9次试跑单独保存，不计入此表。
- 生成只收到问题、实际会话背景和源证据，不传参考答案、预期事实或评分正则。DS Flash 是主回答模型；辩论另一参与者是 Qwen Plus。
- 原文来自清洗后的保险责任表、投保须知、责任免除和四张费率表。完整证据包约6.3万字符，不用模型总结替代条款。
- 内容合格需同时满足事实正确、问项完整和必要条件正确。无需复述所有未问的医院、等待期和额度；会改变本题结论的条件必须保留，不能把有条件结论改成普遍承诺。同一回答已经明确的条件可以承接。
- 可溯源按每句所绑定的证据是否支持全部主张判断。金额计算另检查输入和公式。原文引用存在不等于语义支持；负面断言、缺少资料等判断也要有明确的资料范围依据。
- 使用独立审查 agent 对照原始资料审阅，而非调用一个评分模型给分；主 agent 全量复核最佳版71题，并核对旧版全部失败题及争议题。这里是开发集审查结果，不能当作未知生产问题的准确率保证。
- 辩论版有1题JSON解析失败，仍计入71题分母，没有重跑后择优。

## 六版结果

| 版本 | 内容合格 | 引用充分 | 两者同时合格 | 全部文字生成中位耗时 |
|---|---:|---:|---:|---:|
| 现有默认链路 | 50/71（70.4%） | 未按句绑定，不能直接比较 | — | 1.75秒 |
| 提示词＋现有检索证据 | 47/71（66.2%） | 31/71 | 28/71 | 2.71秒 |
| 提示词＋完整原文证据 | 55/71（77.5%） | 38/71 | 37/71 | 3.03秒 |
| 完整证据＋独立辩论 | 49/71（69.0%） | 32/71 | 27/71 | 29.42秒 |
| 完整证据＋最少必要事实＋来源ID | 58/71（81.7%） | 49/71 | 43/71 | 2.17秒 |
| 上版＋字段化费率＋必要条件提示 | **63/71（88.7%）** | **54/71** | **53/71** | **2.14秒** |

完整证据版独立审查原判52题合格。主 agent 按统一精简口径改判C02、C17、Y023三题：未问的全部条件不强制逐一复述；前段已明确身份条件允许承接；用户身份未知时允许条件化回答。原判、主 agent 改判理由均保留，引用不足判定不变。其余版本无改判。边界判定存在审查者差异，不能将几个百分点差异解释成确定的模型能力差异。

耗时是云端调用完成**全部文字/JSON**的墙钟时间，包含本实验并发条件，不是首字、首音或完整播放时间。最佳版P90为2.79秒，辩论版P90为43.81秒；本轮未调用STT/TTS。

## 具体改动

1. **补齐证据**：原检索可能只命中加油包，漏掉基础住院/门诊；完整包保留责任表全部单元格及结构字段，模型直接理解问题，不额外加入问项拆分模块。
2. **给费率字段名**：将裸CSV行变成“年龄=[26,30]；必选计划_有社保=318……”；仍是原始数据，只改变呈现方式，减少年龄边界和列位置误读。
3. **提示词选必要事实**：只回答本轮问项；保留另购、社保投保身份与结算、合同定义、既往症和指定路径等改变结论的条件。不生成未问的价格或其他责任。
4. **句子和证据共同输出**：模型输出短答句、source_ids及计算推导。程序从冻结源快照展开原文引用，避免模型把改写句当作逐字原文。程序不改答案，也不根据校验失败反复重写。
5. **披露实际系统身份**：AI/TTS身份来自单独runtime来源，不用保险条款证明AI身份。

程序检查只证明来源ID与原文匹配，明确标记未做语义蕴含验证。逐句证据是否足够支持结论，仍由本轮源审查核对。

## 辩论怎样保持独立

两位参与者使用全新上下文、相同原文证据，分别侧重责任边界与金额/条件，但各自先回答完整问题。两份盲答都完成后，才交换答案进行一次证据挑战。最终DS只看到匿名候选和挑战，顺序按问题哈希打乱；提示词禁止以多数、身份或一致意见代替证据。

成功一题共5次模型调用：两份盲答、两份挑战、一次裁决；所有过程记录在calls。没有多轮反思，也没有程序把裁决改成预设答案。

这消除了先看到同伴答案再作答的直接跟风，但不能消除共享证据和模型训练带来的相关错误。实测中，裁决仍出现新错误，例如Y021扣除医保后忘扣年免赔、Y028把性别费率列理解成社保列；C02还把某些责任的60%误扩展到其他责任。不同模型参与不代表裁决一定更准确。

## 一条真实trace：30岁年缴与月缴（C26）

最佳版回答：30岁有社保，必选计划年缴318元、月缴31元；31×12=372元，比年缴多54元。

- 年缴来源：`rate:年缴_必选:8`，年龄区间[26,30]、有社保318。
- 月缴来源：`rate:月缴_必选:8`，同一区间、有社保31。
- 计算：31×12−318=54；结果来自计算，不伪装成原文。
- 早一版曾把30岁读到31–35岁档，答423/42/差81；字段化后的本次结果正确。只证明这一题及本批结果改善，不能推断价格问题永不出错。

另一个正确计算例C03：在费用全符合责任范围、无其他补偿、年免赔尚未使用的假设下，15000−10000=5000；若以有医保身份参保但未用该身份结算，再乘60%=3000。引用分别绑定一般医疗免赔/比例条款，并保留投保身份条件，不把所有未走医保者都归入60%。

## 最佳版仍失败的题

内容失败8题：C01、C02、C07、C09、C19、C20、C29、Y015。完整判定理由保存在逐题审查JSON。

- C01：身份、医院等条件合并后出现“否则60%”，扩大了原文60%的适用范围。
- C09：用户明确已有高血压，回答绕到“如果不是既往症”，没有充分回答当前情境，也没有说明不能保证核保承保。
- C02：质子重离子漏掉大陆地域条件。
- C07：将泛称重病套到约定重疾的转诊与护工服务，没有明确须符合合同定义。
- C19：基因检测有保险责任额度与服务备注两条路径，模型只取其一，未解释路径及源冲突。
- C20：已知投保前结节，仍出现“该责任对结节仍可赔20%”的表述，再补既往症免责不能消除前面的错误暗示。
- C29：肿瘤仅给一般医疗扣1万，遗漏符合合同重疾时可按重疾责任无免赔的关键分支。
- Y015：做出超出所引来源的排他性归属断言，床位范围/例外未交代充分。

另外有内容正确但引用不充分的题，例如合计句只绑定附加包价格、没有同句绑定基础价格；“资料没有最高续保年龄”的否定结论没有资料范围引用。这也是为什么88.7%不能当作准确且可追溯的最终通过率；两者同时通过只有74.6%。

源审查还修正了既有参考口径：须知附录实际存在特殊职业清单，含4吨及以上营运货车司机；不能说资料没有职业清单。货车用户未提供吨位/营运性质时仍需确认。源冲突不应拿单一参考答案强判。

## 后续方向

保留单次DS直接回答，优先把证据按责任、主条款/服务说明、适用条件及费率字段组织清楚。尤其需要让句子引用同时包含父级责任归属与条件，而非只引用数字单元格；对“没有找到”的结论记录实际检索范围。先处理上述失败类型，再用未参与提示词调整的新题验证泛化；本轮不依据开发集结果直接切换生产默认。
