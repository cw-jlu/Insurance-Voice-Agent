# 当前问项与历史待办隔离

更新于2026-10-14，基于远端6373dd1后续开发。本轮修复连续追问时历史已答问题被重新列成当前待办的缺口，没有重算业务准确率或语音时延。

## 原因与实现

exp44 T06实际问的是“投保前有高血压，与高血压无关的交通意外住院是否一定不赔”。输入待办却新增7个历史问项，包括靶向药、质子治疗、免赔额和医院范围。DS没有重新口播这些旧内容，导致待办发布检查拒绝本轮业务答复。完整已播历史仍有必要；问题在于缺少当前问项的来源边界。

现在规划器返回`question`、`user_quote`和`task_id`。程序只接受逐字存在于本轮用户文本的非空原话；历史可以解释“刚才那个”等指代，不能独自创建新待办。明确重问已有问题时复用原任务ID，并要求再次口播，避免新旧措辞差异生成重复任务。仅补年龄、医保或附和不新增问项，继续既有未完成咨询。

年龄、医保等条件更正只重新打开依赖相应字段的已答任务，避免把无关保障介绍一并重新打开。打断调用不指定条件字段时，仍重新打开全部已答任务，未播内容不会被视为完成。独立规划的`seeded`和原话由程序跨轮保存，模型省略这些字段不能解除发布检查。真正的新任务缺少口播段时仍被拦截。

## 局限与下一步
