# 回答链路改动与小样本 trace（2026-10-11）

## 范围

只改文字回答链路与投诉路由，未改 STT、TTS。主模型配置仍是 DeepSeek Flash，但本次实调用返回 402 Insufficient Balance；因此小样本改用临时进程配置 Qwen Plus，不修改生产模型配置。代理 TLS 失败后通过进程 NO_PROXY 直连两个模型服务域名。

## 改动

- 理解模块在现有并行请求中输出 obligations，不额外增加拆题请求；复合问题逐项输出，检查槽位数量。
- 对有依据的常见责任组合用程序短答：住院与门诊共享免赔、ICU另购；既往症与意外分开；基础住院与住院补偿加油包分开。
- 年缴/月缴的全年差额由报价引擎算。一般住院单金额测算明确合规费用、免赔余额、其他补偿等假设；既往症、复杂责任、已使用免赔等情况不使用该测算。
- 支持“一万五”“1万5”金额解析，避免正确派生金额被护栏拒绝。
- trace 记录 plan、resolve、calculate、compose、validate、release，程序路径不伪造模型生成或模型复核记录。
- 投诉优先于挽留；明确停止来电优先结束。
- 清单、续保、社保抵扣缺口需与本句实际问法匹配，避免误判引入额外兜底。

## 额外检查与失败发现

额外实调用 C12、C27 和两个独立投诉会话。C12早期模型路径仍说错“基础版不报销住院费用”；实验开启事实模型复核后，也将此错误放过，并错误解释加油包20%规则。已补基础住院责任证据、明确组合规则、绝对否定住院责任的护栏；自动启用事实模型复核未保留，原显式配置仍可启用。不能把“护栏无违规”当作事实正确。

C27通用生成路径仍有重复、过长、漏说一般门急诊不参与家庭共享等风险。拆题模型也会添加未问事项或返回整个主题目录；这部分尚未解决，不能宣称所有复合题已完善。

投诉“你们天天打电话太烦了”实际会话转人工；同句追加“不要再打电话”实际会话结束、不挽留。原始结果在 `exp23_final_extra_qwen.json`，最终缺口过滤复跑在 `exp23_final3_extra_qwen.json`。

单元回归26项通过，包括金额解析、测算边界、局部兜底、报价差额、投诉优先级和缺口误判。没有运行语音服务，本次不更新摘要的全量 exp21 指标。
