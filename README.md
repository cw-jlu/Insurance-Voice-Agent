# 保险复杂咨询语音 Agent

基于尊享e生百万医疗2026材料的复杂咨询演示项目。当前入口使用`EvidencePipeline`与`CallSession`：完整证据一次生成、会话条件更正、持续咨询待办、来源引用与后置人工请求。旧`Pipeline`和实验脚本保留用于历史对照。

## 当前版本

核心冻结标签：`v0.1.0-core-20261014`。源文件及清洗数据的SHA-256清单见`releases/core-2026-10-14.json`；直接依赖版本见`requirements-core.lock`。冻结是可复现的工程快照，不表示赛题全部通过。

当前完整批次：复杂/复合题26/30（86.7%），整体正确处理133/143（93.0%）；复杂完整口播、附和/回声误停、来源支持和安全人工路由仍有缺口。后续规划修复通过124项单元测试和5个真实Qwen规划用例，完整语音待复验。

## 网页演示

持续语音演示标签：`v0.3.0-duplex-20261014`，在冻结核心之外提供网页服务。配置DeepSeek后默认实时自由提问；未配置时使用离线回放，并提示缺失。Qwen仅用于主动选择的对照。

```powershell
.\start-demo.ps1
```

打开`http://127.0.0.1:8080`。已有依赖时可直接运行`python scripts/run_demo.py`；当前Windows TLS异常环境使用`--native-https`。支持简洁单列对话、一次开启持续收音、播报中插话、附和/回声抑制、说完自动提交、0.75–2倍播放、连续咨询、条件更正、实时阶段耗时、完整原文溯源、逐轮生成/已播记录、JSON导出和3+7+5分钟演练计时。

页面顶部可切换“用户咨询”和“主动推销”。主动推销需选择实时模型，点击“开始推销演示”后由AI先开场，再按需求、报价、限制、健康告知和投保询问推进；中途可提问、插话、拒绝或要求人工。开场也受逐句播放回执和取消机制约束，短信及人工仍只记录请求。切换业务场景会新建会话；也可直接打开`http://127.0.0.1:8080/?scenario=outbound`进入主动推销。

用户同意听介绍后，AI先说明产品能解决的问题、主要保障与关键条件；用户愿意继续，再讲普通住院和大病保障，不将“愿意听”当成购买意愿。实际问题仍进入证据咨询链路，明确拒绝或不方便时结束介绍。介绍进度以完整播放回执为准，中途打断不会被标记为已介绍完。

主动推销的每轮输入由Qwen小模型结合当前原话、完整已播历史、生成/已播介绍记录和咨询待办选择受限工具：播放指定介绍、进入证据咨询、回顾用户原问题、回应附和、澄清或结束通话。固定话术是可调用的素材，不靠关键词直接触发；续讲跳过已经确认播完的句子，明确要求讲下一部分时可转到保障介绍。模型返回无效工具或超时时只澄清，不默认重播或推进销售。`turns[].dispatch`与阶段耗时记录保留工具选择，生成内容不作为已播历史。

普通保费咨询先由小模型调用报价条件收集，程序逐项追问缺失的被保人年龄、基本医保及投保适用范围，条件齐全再进入证据回答，不用完整证据模型判断“该问几岁”。条件更新只取用户明确陈述的可解析字段，假设或比较不写入画像。Web业务模型禁用自动重试；Windows HTTPS传输单次总预算为12秒，业务等待另有18秒截止检查，超时明确暂停并保留原问题，迟到的结果不提交到新会话状态。

Web服务启动后在后台预生成开场、承接和固定流程话术，音频保存在Git忽略的`demo-runtime/speech/`。缓存按话术、模型、音色及音频格式区分，跨会话和重启复用；命中后不再请求TTS。未准备好的固定话术立即使用浏览器朗读，避免现场等待云端合成。动态回答仍实时合成，先等待服务端的会话创建和配置确认再发送文本。`/api/health`中的`speech_cache`提供预热状态及安全错误码，不代表账户剩余额度。

可选容器启动：`docker compose up --build -d`。凭据使用`.env.demo.example`对应的本地`.env.demo`，不进入镜像或Git。完整步骤、已测范围及容器未实测说明见[Web服务与冻结版本](docs/30-Web演示服务与冻结版本.md)。

验证冻结核心：`python scripts/verify_freeze.py`。持续语音版143项Python测试和7项Node状态测试通过，业务准确率和语音指标不因包装自动提升。配置检查：`python scripts/check_demo.py`。打包：`python scripts/package_submission.py`。
